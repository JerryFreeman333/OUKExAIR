# 图灵研究院 · 创新社区大屏

温州市图灵人工智能高等研究院创新社区的多视图展示页：一张可点击进入的海报封面，加上带现场大屏的社区总览、成员成长天梯、活动打卡与作品现场。

在线访问：<https://jerryfreeman333.github.io/OUKExAIR/>

全部使用原生 HTML / CSS / JavaScript，无构建步骤、无框架，可直接双击 `index.html` 打开，也可以放到任意静态服务器上。

点击海报封面即可直接进入，无需登录或授权。进入应用后，连续 10 分钟没有鼠标、键盘、触摸或滚动交互，页面会自动返回封面。

## 快速开始

### 方式一：直接打开

双击 `index.html`。字体通过 Google Fonts 加载；断网时会使用系统字体，功能不受影响。

> 部分浏览器对 `file://` 下的 localStorage 限制不同，建议用本地服务器打开，数据会更稳定。

### 方式二：本地服务器

```bash
cd 图灵大屏
python3 -m http.server 8899
```

打开 <http://localhost:8899/index.html>。

## 总览现场大屏

现场大屏已经成为总览的一部分，不再设置重复的独立入口。进入总览即可查看，点击画面暂停或继续，双击画面或点击控制台按钮进入全屏。

| 入口 | 行为 |
| --- | --- |
| 总览左侧大屏 | 自动轮播成员成长、作品、活动数据与奶龙等级 |
| 点击画面 | 暂停 / 继续轮播 |
| 双击画面 | 进入或退出全屏 |

自动模式根据当前真实数据生成画面：成员天梯、热门作品、活动数据和奶龙成长。

每个画面停留 9 秒。控制台顶部可切换「自动 / 成员 / 数据 / 作品」。

总览右侧的数据卡可直接跳转到成员、活动或作品页；页面切换使用蓝橙扫场动画。作品卡支持鼠标倾斜反馈，并可通过 `Enter` 打开详情。

### 键盘

| 按键 | 功能 |
| --- | --- |
| `Space` | 暂停 / 继续轮播 |
| `←` / `→` | 上一屏 / 下一屏 |
| `F` | 全屏 |
| `Esc` | 退出全屏 / 关闭弹窗 |

挂机建议：用 Chrome 或 Edge 打开页面，进入总览后按 `F` 全屏，并在系统设置中关闭自动休眠。当前版本的数据保存在本机浏览器中，换一台机器需要重新录入或接入后端。

## 页面

- **封面**：直接使用此前确认的 OUKE「AIR」主视觉海报原图，点击任意位置进入。
- **总览**：社区规模、现场大屏、最近一场活动、到场曲线与研究院介绍。
- **成员成长天梯**：奶龙等级与成员排名合并为一条交互链路，等级筛选会同步更新榜单、平均活跃指数和右侧成长档案。
- **活动打卡**：累计到场、场均人数、回访率、最热主题，到场曲线、回访甜甜圈、主题热度、数据解读和逐场活动表。
- **作品现场**：可直接「加入作品」，填写标题、主创、类型、主题与封面视觉；支持个人 / 综合 / 同主题分类、主题筛选、作品搜索、详情查看和送上大屏。
- **奶龙成长**：七级成长体系已经合入成员成长天梯，不再使用单独板块。
- **现场大屏**：作品、成员、数据、奶龙四种画面，支持自动轮播、分页、暂停和全屏。

## 现场打卡

点击右上角「活动打卡」或页面中的「现场打卡」：

1. 选择本场活动（默认最新一场）。
2. **我是老成员**：搜索姓名，点击 `+` 完成签到；已签到的人会置灰并排在后面。
3. **我是新朋友**：填写姓名、身份、学校/单位，可拍照或上传头像，勾选头像使用说明后提交。
4. 新成员自动进入 Lv.1「奶蛋」，并记录本场签到；再次到场后会继续成长。

头像会在浏览器内裁剪为 220 × 220 的 JPEG，以 data URL 形式保存在 localStorage；不会上传到服务器。建议在采集前明确告知用途并取得同意。

底部左侧的圆形按钮可恢复初始演示数据，会清除本机保存的打卡和头像。

## 评分与等级

活跃指数满分 100：

```
活跃指数 = 到场 58% + 作品 26% + 连续参与 16%
```

- **到场**：8 场活动按时间加权，权重从 `0.5` 逐步提高到 `1.4`，越近的活动影响越大。
- **作品**：个人作品与联合作品都计入，最多按 6 件计算。
- **连续参与**：按最近连续到场场次计算，最多 8 场。

等级阈值：

| 等级 | 名称 | 活跃指数 |
| --- | --- | --- |
| Lv.1 | 奶蛋 | 0–11 |
| Lv.2 | 奶鼠 | 12–23 |
| Lv.3 | 奶狗 | 24–35 |
| Lv.4 | 豆奶 | 36–47 |
| Lv.5 | 奶鱼 | 48–59 |
| Lv.6 | 奶蛙 | 60–71 |
| Lv.7 | 西格玛奶蛙 | 72+ |

首次打开时成员、活动和作品均为空，页面会引导从「登记成员」或「加入作品」开始；录入的数据保存在当前浏览器中。

## 数据与持久化

- localStorage 键名：`turing-community-screen-v3`
- 顶层结构：`{ version, members, events, works }`
- 成员签到位图：`member.att` 是长度等于活动数的 `0/1` 字符串，例如 `11001111` 表示第 1、2、5、6、7、8 场到场。
- 作品字段：`author` 为成员 id，`co` 为联合创作者 id 数组，`theme` 用于同主题策展，`type` 为「个人 / 综合 / 同主题」。
- 头像字段：`member.photo` 为 JPEG data URL，可能为空。

数据只在当前浏览器、当前站点下有效。清除浏览器站点数据或点击重置按钮都会恢复种子数据。

## 替换演示数据

编辑 `assets/js/data.js`：

- `MEMBER_SEED`：`[姓名, 英文名, 身份, 学校/单位, 签到位图, 一句话]`
- `EVENT_SEED`：活动日期、标题、主题、预期人数、满意度、场地、备注
- `WORK_SEED`：作品标题、作者 id、联合作者 id、主题、类型、年份、推荐值、视觉母题、描述、标签

注意事项：

1. 增加或删除活动时，同步修改每位成员的 `att` 长度；旧数据的签到索引按活动顺序对应。
2. 成员 id、活动 id、作品 id 建议保持从 0 开始连续；页面中的关联（作者、联合创作、跳转）都依赖 id。
3. 修改后打开页面，点击左侧栏重置按钮，或清除 localStorage 中的 `turing-community-screen-v3`，让新种子数据生效。
4. 如果只想临时加人，用「现场打卡 → 我是新朋友」更方便，不需要改代码。

│   └── js/
│       ├── data.js         # 种子数据、评分、等级、统计派生
│       ├── mascots.js      # 奶系角色图片、头像、作品视觉

## 设计与素材

- 色彩：沿用首发版本的海报体系，纸白 `#f3f0e7`、墨蓝 `#0e1a2c`、电蓝 `#1c46e8`、橙 `#f4511e`、黄 `#ffc400`。
- 版面：网格纸底、墨色粗边框、硬边投影、几何色块与大字号标题；总览、成员天梯、活动和作品保留原有信息架构。
- 交互：封面直接进入、总览数据卡跳转、页面切换扫场、大屏暂停/切换/全屏、等级联动筛选、作品卡倾斜与键盘打开。

## 生产化建议

当前是纯前端演示版。正式上线前建议：

1. 把 `assets/js/data.js` 的数据层替换为后端 API，解决多设备同步和大屏与手机端数据一致的问题。
2. 为头像采集增加更明确的隐私告知、删除入口和保留期限。
3. 增加数据导出 / 导入，便于活动结束后归档。
4. 大屏机器使用固定 URL + 全屏 + 关闭休眠；如果浏览器会清理站点数据，考虑用 kiosk 模式或每日自动重建数据。
